# 🐸 Cóc Kiện Trời - Vượt Thiên Đình

> **Trò chơi Platformer Parkour 2D thẳng đứng theo tích truyện cổ tích Việt Nam "Cóc Kiện Trời".**  
> Điều khiển chú Cóc kiên cường nhảy qua các tầng trời từ mặt đất nắng hạn, rừng thiêng, mây giông đến Nam Thiên Môn (1000m) để gõ vang chiếc Trống Thiên Đình, đòi lại công lý và nguồn mưa lành cho muôn loài!

---

## 📖 Cốt Truyện Dân Gian

Thuở xưa, trần gian gặp nạn đại hạn kéo dài nhiều năm. Ruộng đồng nứt nẻ chân chim, cỏ cây khô héo rũ rượi, muôn loài khát cháy cổ họng mà không thấy một hạt mưa rơi. Thấy muôn loài lâm vào cảnh diệt vong, một chú Cóc nhỏ bé nhưng giàu lòng dũng cảm quyết chí một mình lên tận Thiên Đình để gõ trống kiện Ngọc Hoàng đòi mưa cứu thế gian.

Trên hành trình trèo đèo lội suối, vượt qua các vách núi dựng đứng và ngút ngàn tầng mây, Cóc kết nghĩa với Cua đồng, Ong vò vẽ, Cọp dữ và Gấu đen cùng chung chí hướng. Nhờ tài trí mưu lược và cú nhảy chuẩn xác, Cóc đã qua mặt tướng nhà Trời, gõ vang chiếc trống sấm Thiên Đình buộc Ngọc Hoàng phải truyền lệnh cho Long Vương làm mưa phủ khắp nhân gian.

## ✨ Tính Năng Nổi Bật

- **🎮 Lối chơi Parkour tinh giản & cuốn hút:** Nhảy leo bệ đứng liên tục theo trục dọc, kết hợp cơ chế búng nhảy đệm lần 2 trên không (Double Jump) để vượt qua những khoảng cách hiểm hóc.
- **📱 Hỗ trợ đa nền tảng tối đa:** Tương thích hoàn hảo với cả máy tính (bàn phím + chuột) và điện thoại/máy tính bảng (màn hình cảm ứng + nút ảo).
- **🌿 3 Làn bệ đứng cân bằng (Tỉ lệ 1:1:1):** Người chơi tự do tính toán lộ trình tối ưu qua các bệ:
  - **Lá Sen Thần:** Bật nảy siêu cao lơ lửng giữa không trung.
  - **Trống Sấm Đông Sơn:** Kích hoạt siêu phóng vút mây qua hiểm cảnh.
  - **Bệ Đất Nứt (Có cơ chế Hồi Phục):** Rung nứt và vỡ vụn khi giẫm chân lên (0.75s để nhảy thoát), sau khoảng 3 giây vỡ vụn sẽ tự động tái tạo và hồi sinh nguyên vẹn kèm đồng hồ tiến độ `⏳ Hồi phục...` cùng hiệu ứng ánh sáng thần kỳ.
  - **Bệ Mây:** Bệ mềm mỏng, tan biến sau khi giẫm.
  - **Bệ Tre Di Chuyển:** Bệ đứng đung đưa trái - phải nhịp nhàng.
- **🦀 Liên Minh Bạn Đồng Hành:**
  - **Cua Đồng (Cua Giữ Thăng Bằng):** Giúp giữ thăng bằng tuyệt đối, giảm trơn trượt khi tiếp đất.
  - **Ong Vò Vẽ (Ong Lượn Mây):** Giúp lượn nhẹ khi rơi bằng cách giữ phím Nhảy.
  - **Cọp Rừng (Cọp Hộ Thể):** Cứu sinh 1 lần khi sảy chân rơi tự do, tạo cơn lốc hất ngược lên bệ an toàn.
  - **Gấu Núi (Gấu Hút Sương):** Bán kính hút sương cứu hạn rộng gấp đôi bình thường.
- **🎭 Kho Trang Phục Dân Gian Độc Đáo:** Mở khóa Cóc Vàng May Mắn, Cóc Hoa Sen, Cóc Giáp Đồng Đông Sơn, Cóc Thần Mưa.
- **🎵 Âm Nhạc Ngũ Cung Dân Gian:** Toàn bộ nhạc nền và hiệu ứng âm thanh được tổng hợp bằng Web Audio API (không cần tải file âm thanh ngoài).
- **🏆 Bảng Vàng Thành Tích:** Lưu trữ lịch sử các lần leo, kỷ lục thời gian, độ cao cao nhất và các danh hiệu đã đạt được.

## 🕹️ Hướng Dẫn Điều Khiển & Cách Chơi

### 1. Trên Máy Tính (PC / Laptop)
| Thao Tác | Phím / Thao Tác Chuột | Tác Dụng |
| :--- | :--- | :--- |
| **Nhảy từ bệ** | `Space` / `W` / `Mũi tên Lên` | Cóc nhún chân phóng vút lên cao |
| **Búng nhảy trên không** | Nhấn `Space` / `W` / `Mũi tên Lên` lần 2 | Nhảy đệm giữa không trung để đổi hướng hoặc với tới bệ xa |
| **Di chuyển Trái / Phải** | `A` / `D` hoặc `Mũi tên Trái` / `Phải` | Lượn hướng ngang khi đang bay hoặc chạy trên bệ |
| **Lượn chậm khi rơi (Ong)**| Giữ phím `Space` khi đang rơi | Giảm tốc độ rơi tự do để căn điểm hạ cánh chính xác |
| **Chơi bằng Chuột** | **Click chuột trực tiếp lên màn hình game** | Chạm bên trái nhảy sang trái, chạm bên phải nhảy sang phải, chạm giữa nhảy thẳng |

### 2. Trên Điện Thoại & Máy Tính Bảng (Màn Hình Cảm Ứng)
- **Chạm trực tiếp vào màn hình:**
  - Chạm nửa bên trái màn hình: Nhảy hướng sang trái.
  - Chạm nửa bên phải màn hình: Nhảy hướng sang phải.
  - Chạm ở giữa màn hình: Nhảy thẳng đứng lên trên.
  - Chạm lần 2 khi đang ở trên không: Búng chân nhảy đệm lần 2.
- **Nút cảm ứng ảo ở góc dưới:**
  - Nút **[ Qua Trái ⬅️ ]** & **[ Qua Phải ➡️ ]** ở góc trái dưới.
  - Nút **[ NHẢY ⬆️ ]** to bản màu cam ở góc phải dưới.

### 3. Cài Đặt Ứng Dụng Cho Điện Thoại Android / Tải File .APK

#### 🚀 Cách 1: Cài đặt trực tiếp 1 chạm (Khuyên dùng - Chuẩn Google WebAPK)
> **💡 Lưu ý quan trọng:** Đây là giải pháp tốt nhất được Google phát triển chính thức cho Android. Trình duyệt Google Chrome sẽ tự động biên dịch game thành ứng dụng native (WebAPK) gắn trực tiếp vào máy, **100% không bị báo lỗi cú pháp gói, không bị Play Protect chặn, và không cần cấp quyền nguồn không xác định**!

1. Mở liên kết game trên trình duyệt **Google Chrome** hoặc **Cốc Cốc** trên điện thoại Android.
2. Bấm nút **"Tải Android / APK"** ngay trên thanh tiêu đề game (hoặc chọn biểu tượng menu 3 chấm `⋮` ở góc trên bên phải trình duyệt).
3. Chọn **"Cài đặt ứng dụng"** (hoặc **"Thêm vào Màn hình chính"**).
4. Biểu tượng **Cóc Kiện Trời** sẽ xuất hiện trên màn hình điện thoại như ứng dụng tải từ CH Play, mở lên chơi full màn hình 60 FPS, không có thanh địa chỉ web và lưu điểm kỷ lục hoàn toàn tự động!

---

#### 📦 Cách 2: Build File APK Trực Tiếp Bằng Mã Nguồn Android Native (Capacitor)
Dự án đã tích hợp sẵn 100% dự án Android Studio tại thư mục `/android`:
```bash
# 1. Đồng bộ mã nguồn web sang dự án Android
npm run build:android

# 2. Build file APK trực tiếp bằng Gradle (không cần mở Android Studio)
cd android && ./gradlew assembleDebug

# File APK được tạo tại:
# android/app/build/outputs/apk/debug/app-debug.apk
```
*Hoặc mở thư mục `android/` bằng **Android Studio** $\rightarrow$ chọn **Build** $\rightarrow$ **Build Bundle(s) / APK(s)** $\rightarrow$ **Build APK(s)**.*

#### 🌐 Cách 3: Đóng gói thành file `.apk` trực tuyến qua PWABuilder (Không cần Android Studio)
Nếu bạn không cài đặt Android Studio mà muốn tạo file `.apk` online:
1. Sao chép liên kết chia sẻ của game: `https://ais-pre-5u62ceutjx6td44bt4noe6-652258248200.asia-northeast1.run.app`
2. Mở công cụ chuyển đổi PWA sang APK chính thức của Google & Microsoft: [PWABuilder.com](https://www.pwabuilder.com)
3. Dán liên kết game vào ô tìm kiếm và bấm **"Start"** (Dự án đã đạt 100% tiêu chí PWA với đầy đủ Screenshots và Service Worker).
4. Chọn **"Package for Android"** -> Tải gói về máy.
5. **Quan trọng:** Gói tải về sẽ có tên là `Android.zip`. Mở ứng dụng **Quản lý tệp (Files)** trên điện thoại -> **Giải nén file zip này** -> Vào thư mục giải nén mở file `app-release.apk` để cài đặt.

#### ⚠️ Hướng Dẫn Sửa Toàn Bộ Các Lỗi Khi Cài File APK Trên Điện Thoại:

1. **Lỗi "Có vấn đề khi phân tích cú pháp gói" (Parse Error / Lỗi cú pháp) hoặc "Không thể mở tệp":**
   - **Nguyên nhân:** File bạn tải về từ PWABuilder thực chất là file nén **`Android.zip`**, không phải là file `.apk` thuần. Nếu bạn bấm trực tiếp vào file zip để cài đặt thì Android sẽ báo lỗi cú pháp.
   - **Khắc phục:** Mở ứng dụng **Quản lý tệp (Tệp của bạn / Files)** trên điện thoại -> Vào mục **Tải về (Download)** -> Nhấn giữ vào file `Android.zip` -> Chọn **"Giải nén" (Extract)** -> Sau khi giải nén xong, mở thư mục ra sẽ thấy file có đuôi `.apk` (như `app-release.apk`) -> Bấm vào file `.apk` đó để cài đặt!

2. **Lỗi "Ứng dụng bị chặn bởi Play Protect / Chưa được xác minh":**
   - **Nguyên nhân:** File APK tự đóng gói qua các công cụ trực tuyến sử dụng khóa bảo mật cá nhân (chưa được duyệt trực tiếp lên kho CH Play của Google) nên Play Protect sẽ hiện cảnh báo bảo mật.
   - **Khắc phục:** Khi màn hình cảnh báo của Play Protect hiện lên:
     + **KHÔNG** bấm "Hủy" hoặc "OK".
     + Bấm vào dòng chữ nhỏ **"Chi tiết" (More details)** hoặc biểu tượng mũi tên chỉ xuống.
     + Bấm chọn dòng **"Vẫn cài đặt" (Install anyway)** để hoàn tất.

3. **Lỗi "Vì lý do bảo mật, điện thoại không được phép cài đặt ứng dụng từ nguồn này" (Install Unknown Apps):**
   - **Nguyên nhân:** Android mặc định tắt tính năng cài ứng dụng ngoài CH Play để bảo vệ máy.
   - **Khắc phục:** Khi thông báo hiện ra, bấm vào nút **"Cài đặt" (Settings)** -> Gạt bật công tắc xanh **"Cho phép từ nguồn này" (Allow from this source)** cho ứng dụng Chrome hoặc Quản lý tệp -> Bấm phím quay lại (Back) và bấm **"Cài đặt"** là xong!

4. **Lỗi không kết nối được hoặc link lỗi trên PWABuilder:**
   - **Nguyên nhân:** Link game chưa được mở chia sẻ công khai.
   - **Khắc phục:** Trên thanh công cụ AI Studio, hãy bấm nút **"Share" (Chia sẻ)** để đảm bảo link ở chế độ công khai trước khi dán vào PWABuilder.

## 🛠️ Hướng Dẫn Cài Đặt & Chạy Môi Trường Cục Bộ (Local)

### 1. Yêu cầu hệ thống
- **Node.js**: Phiên bản `>= 18.0.0` (Khuyên dùng bản LTS mới nhất).
- **Trình quản lý gói**: `npm`, `pnpm` hoặc `bun`.

### 2. Các bước cài đặt

```bash
# 1. Di chuyển vào thư mục dự án
cd coc-kien-troi

# 2. Cài đặt các thư viện phụ thuộc
npm install

# 3. Khởi chạy máy chủ phát triển (Development Server)
npm run dev
```

Sau khi chạy lệnh trên, mở trình duyệt web và truy cập vào đường dẫn:
```text
http://localhost:3000
```

### 3. Các lệnh hữu ích khác

```bash
# Kiểm tra lỗi cú pháp và kiểu dữ liệu TypeScript
npm run lint

# Đóng gói ứng dụng cho môi trường Production
npm run build

# Xem trước bản đóng gói Production
npm run preview
```

## 💡 Mẹo Để Đạt Điểm Cao & Vượt Thiên Đình (1000m)

1. **Tận dụng Búng Nhảy Lần 2:** Đừng vội bấm nhảy lần 2 ngay sau khi rời bệ, hãy chờ Cóc đạt đỉnh parabol của cú nhảy đầu tiên rồi mới bấm lần 2 để tối ưu hóa độ cao.
2. **Khai thác Bệ Lá Sen Thần:** Bệ lá sen có lực nảy mạnh hơn 120% bệ thông thường. Hãy cố gắng hạ cánh vào giữa lá sen.
3. **Cảnh giác với Bệ Nứt:** Bệ nứt sẽ vỡ tan sau khi giẫm lên khoảng 0.7 giây. Hãy nhảy sang bệ khác ngay khi tiếp đất!
4. **Kết nạp Cọp Rừng:** Khi có đủ 80 giọt sương, hãy mở khóa Cọp Rừng. Bạn sẽ có thêm 1 mạng an toàn nếu lỡ sảy chân rơi tự do.
